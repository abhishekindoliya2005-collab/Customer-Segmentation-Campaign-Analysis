# Project Report — Customer Segmentation & Campaign Analysis

## Objective
Analyze customer behavior using RFM and evaluate campaign response/conversion performance.

## Dataset
2,200 synthetic transactions from 650 customers across 2025.

## Main Methods
- Data validation
- Customer aggregation
- RFM scoring
- Customer segmentation
- Campaign response analysis
- Conversion analysis
- Power BI visualization

## Portfolio Results
- Total customers: 629
- Total orders: 2200
- Total revenue: ₹10,291,944.54
- Average order value: ₹4,678.16
- Highest-revenue campaign: Festival Offer
- Highest-revenue segment: Loyal Customers

## Limitations
The dataset is synthetic. Campaign performance is observational and should not be interpreted as causal evidence without experimentation.
